# Drop your art here

Save a picture as `<slot>.png` in this folder (WebP, JPG and SVG work too) and the game uses it instead of the placeholder. The slot names and sizes are listed in `art/SLOTS.md`.

- Paint over a copy of `art/templates/<slot>.png` so the size and pivot line up.
- In the game, press **F3** to see every template in place and **F4** to reload art without restarting.
- Delete the file to get the placeholder back.
